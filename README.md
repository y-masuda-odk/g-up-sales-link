# G-UP Sales Link

営業活動で収集した顧客課題をグループ内・パートナー間で共有し、登録済みの商材とAIでマッチングする営業支援ツールのプロトタイプです。

## 現在の実装

- 営業先（会社・大学・部署）と担当者、営業ステータスの一覧表示
- 営業案件とヒアリングした課題の可視化
- 課題と商材のAIマッチング提案UI
- 商材保有者へ連携するための導線
- Cloudflare D1向けのDrizzleスキーマと初期マイグレーション
- OpenAI Sites向けの公開設定

## ローカル開発

必要環境:

- Node.js 22.13.0以上
- pnpm 11.25.0

```bash
pnpm install
pnpm dev
```

ビルド確認:

```bash
pnpm build
```

## 主なファイル

- `app/page.tsx`: メイン画面とプロトタイプの状態・データ
- `app/globals.css`: デザインとレイアウト
- `db/schema.ts`: D1/Drizzleのデータモデル
- `drizzle/`: DBマイグレーション
- `.openai/hosting.json`: OpenAI Sitesのプロジェクト設定

## 次の開発候補

1. 画面内のサンプルデータをD1へ移行する
2. 営業案件・顧客課題・商材の登録／編集機能を実装する
3. ユーザー認証と組織・権限管理を追加する
4. AIマッチングを実データとモデル呼び出しへ接続する
5. 通知、コメント、担当者への提案フローを実装する
